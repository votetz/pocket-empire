# Wrathborn

A turn-based strategy game where you lead a faction to dominance through warfare, city management, and tactical combat.

## Concept

Take control of one faction and lead it to victory against AI-controlled enemies. Capture cities, manage armies, and outlast your opponents.

## Current State

Console prototype in active development. Core systems being built before moving to LibGDX for rendering.
